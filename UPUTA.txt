DESCO — hosting na GitHub Pages
================================

1. U repou stranicaDiego obriši stare datoteke.
2. Uploadaj SADRŽAJ ove mape izravno u root repoa
   (index.html, app.js, assets, images, o-nama...).
   NE stavljaj još jednu mapu desco-website unutra.
3. GitHub → Settings → Pages → Deploy from branch → main / (root).
4. Pričekaj minutu i osvježi https://ako560.github.io/stranicaDiego/

Mora izgledati ovako:
  stranicaDiego/index.html
  stranicaDiego/app.js
  stranicaDiego/logo.png
  stranicaDiego/images/hero.jpg
  stranicaDiego/o-nama/index.html
