DESCO — zadnji ZIP za GitHub (stranicaDiego)
===========================================

1. Raspakiraj ZIP (Extract all).
2. GitHub: Add file → Upload files.
3. Ctrl+A na SVE (i mapu images) → povuci na GitHub.
4. Commit changes. Pričekaj minutu i osvježi stranicu.

VAŽNO: mapa images mora ići na GitHub (unutar nje su nacrti projekata).
