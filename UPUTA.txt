DESCO — ZIP za GitHub Pages (stranicaDiego)
==============================================

1. Raspakiraj ZIP (Extract all).
2. GitHub → Add file → Upload files.
3. Označi SVE datoteke i mapu images (Ctrl+A) i povuci na GitHub.
4. Commit changes. Pričekaj minutu i osvježi:
   https://ako560.github.io/stranicaDiego/

VAŽNO:
- Uploadaj sadržaj ZIP-a izravno u root repoa (index.html mora biti u rootu).
- NE stavljaj još jednu mapu unutra.
- Mapa images MORA ići na GitHub (unutar nje su projekti i usluge).
