DESCO — HTML popravak za GitHub Pages
========================================

Na GitHubu su nacrti već uploadani, ali HTML traži krivi folder
(images/p/...). Ove HTML datoteke pokazuju na postojeće mape.

1. Raspakiraj ovaj ZIP.
2. GitHub → Add file → Upload files.
3. Označi SVE .html datoteke i povuci ih na GitHub (overwrite).
4. Commit changes. Pričekaj minutu i osvježi:
   https://ako560.github.io/stranicaDiego/projekti.html

Ne treba ponovno slati mape slika.
